# smartHr releases

Installers for smartHr, the HR system of Digital Machinery Equipment.
The source code is kept in a separate private repository.

- smartHr-Admin-Setup-X.Y.Z.exe: the HR/admin app for Windows
- smartHr-Admin-X.Y.Z.msix: the same app as an MSIX package
- smartHr-X.Y.Z.apk: the employee app for Android
- SHA256SUMS: checksums the apps check before installing an update

Download the latest from Releases. After the first install, both apps update themselves.
